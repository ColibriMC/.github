# ColibriMC

ColibriMC is a proprietary, high-performance server core engineered for Minecraft 26.2. Designed specifically for low-memory environments, it eliminates per-tick overhead while supporting adapted plugins.

---

## Key Features

- **Minimal Memory Footprint:** Engineered to run efficiently on strictly constrained memory budgets.
- **Zero Per-Tick Overhead:** Eliminates redundant tick-loop processing to maximize throughput.
- **Adapted Plugin Ecosystem:** Run tailored plugins without sacrificing performance.

---

## Requirements

- **Java Runtime Environment:** Java 21 or higher.
